# 03. 사용자 플로우 & 화면 구성

## 사용자 플로우
1. **이력서 등록**: 페이지 접속 시 저장된 이력서가 자동으로 채워진다. 처음이면 직접
   붙여넣거나 `.txt`/`.md`/`.pdf` 파일을 업로드한다. PDF는 서버에서 텍스트를 추출해
   textarea에 채워준다.
2. **JD 입력**: 지원하려는 채용공고 JD를 붙여넣는다.
3. **AI와 대화**: 채팅 입력창에 "이 JD에 맞게 백엔드 경험을 더 강조해줘" 같은 요청을 보낸다.
   이력서 + JD + 지금까지의 대화 이력이 매번 함께 서버로 전송된다.
4. **응답 확인**: AI가 대화형 답변(`reply`)을 보여주고, 수정을 제안하는 경우 메시지 아래에
   "이 수정본 적용" 버튼이 함께 나타난다.
5. **적용/버전 관리**: 버튼을 누르면 이력서 textarea가 교체되고, 그 시점 텍스트가 새 버전으로
   버전 목록에 쌓인다. 이전 버전은 언제든 목록에서 "복원" 가능.
6. **반복**: 3~5를 필요한 만큼 반복하며 이력서를 다듬는다.
7. **내보내기**: 최종본을 "이력서 복사" 또는 "텍스트 다운로드"로 꺼낸다.

## 화면 구성 (2단 레이아웃, `index.html` 기준)

```
┌─────────────────────────────────────────────────────────┐
│  resume-matcher                                          │
│  이력서 + 채용공고를 넣고 AI와 대화하며 다듬어보세요            │
├───────────────────────────┬───────────────────────────────┤
│  [이력서 패널]              │  [채팅 패널]                    │
│  - 파일 업로드 버튼          │  - AI 모델 선택 드롭다운          │
│    (.txt/.md/.pdf) + 파일명 │    (Claude / Gemini)           │
│  - 이력서 textarea          │  - 대화 메시지 목록              │
│    (자동 저장 인디케이터)    │    (user / assistant / system) │
│  - JD textarea              │    assistant 메시지 중 수정 제안 │
│  - [복사] [다운로드] 버튼    │    이 있으면 "적용" 버튼 표시     │
│  - 버전 기록 목록            │  - 입력창 + 보내기 버튼          │
│    (시간 · 미리보기 · 복원)  │    (Enter 전송 / Shift+Enter    │
│    [전체 삭제]              │     줄바꿈)                     │
└───────────────────────────┴───────────────────────────────┘
```

- 왼쪽 패널: 입력/버전/내보내기 담당. 오른쪽 패널: 대화 담당.
- 적용된 수정본을 반영한 채팅 메시지에는 "✓ 이 수정본을 적용했습니다" 라벨이 영구 표시되어,
  대화 스크롤을 올려도 어떤 제안을 실제로 반영했는지 추적 가능.
- 버전 목록은 최신순으로 표시되며 각 항목은 저장 시각과 본문 앞 40자 미리보기를 보여준다.

## 상태 저장 위치 (localStorage 키)
| 키 | 내용 |
|---|---|
| `rm:resume` | 현재 이력서 텍스트 |
| `rm:jobDescription` | 현재 JD 텍스트 |
| `rm:versions` | 이력서 버전 배열 `{id, createdAt, text}[]` |
| `rm:chat` | 채팅 이력 `{role, content, updatedResume, applied}[]` |
| `rm:provider` | 선택된 AI 프로바이더 (`"claude"` \| `"gemini"`) |
