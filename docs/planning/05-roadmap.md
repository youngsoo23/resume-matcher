# 05. 로드맵 & 범위 밖

## 지금까지 완료된 MVP
최초 `PLANNING.md`에서 정의한 MVP 4개 항목은 모두 구현 완료됐다.
- `/api/chat` 엔드포인트 (Claude API 연동, 구조화 응답)
- 한 페이지 프론트(이력서/JD 입력, 채팅 패널, 적용 버튼)
- localStorage 기반 버전 히스토리 (목록 + 복원)
- 이력서 복사/다운로드

추가로, 최초 계획에는 없었지만 이후 구현된 것:
- PDF 업로드 → 서버 텍스트 추출 (`/api/resume/extract`)
- 버전 전체 삭제 기능
- 적용된 수정본에 대한 채팅 메시지 라벨 고정("✓ 적용했습니다")

## 다음에 고려할 것 (우선순위 순, 확정 아님)
1. **오류 재시도**: 채팅 요청 실패 시 "다시 시도" 버튼 (현재는 메시지 다시 입력해야 함).
2. **버전 diff 보기**: 버전 목록에서 이전/현재 버전 간 변경점을 하이라이트.
3. **JD 다중 관리**: 여러 채용공고를 탭이나 목록으로 관리 (현재는 JD 슬롯 1개, 덮어쓰기).
4. **스캔 PDF 대응**: 텍스트 레이어 없는 PDF에 대한 OCR 또는 안내 개선.

## 범위 밖 (당분간 하지 않음)
- 다중 사용자 / 로그인 / 인가
- 이력서 자동 점수화·평가 기능
- 채용공고 크롤링/자동 수집
- 배포 자동화(CI/CD), 클라우드 호스팅
- 서버 측 DB 도입 (localStorage만으로 개인용 툴 목적에 충분하다고 판단)
