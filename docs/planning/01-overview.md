# 01. 개요

## 한 줄 소개
내 이력서와 채용공고(JD)를 넣으면, AI와 대화하며 그 공고에 맞게 이력서를 다듬어주는 개인용 툴.

## 배경 / 문제 정의
- 구직 시 지원할 공고마다 이력서를 조금씩 다르게 다듬어야 하는데, 매번 수작업으로 강조 포인트를
  바꾸는 건 번거롭고 일관성도 떨어진다.
- ChatGPT/Claude 같은 범용 챗봇에 붙여넣고 대화하는 것도 가능하지만, 이력서 원문·JD·대화
  맥락을 매번 다시 붙여넣어야 하고, 수정본을 버전별로 관리하기도 불편하다.
- 이 툴은 "이력서 + JD + 대화 맥락"을 항상 유지한 채로 대화하고, 제안된 수정본을 바로
  적용/버전관리할 수 있게 해서 이 반복 작업을 줄이는 것이 목적이다.
- 실제 동기: 개발자 본인이 이직/구직을 준비하며 직접 쓰려고 만든 도구다. 지원 공고마다
  이력서를 빠르게 맞춤화하려는 실용적 목적과 함께, Kotlin/Spring Boot 백엔드에서 Claude
  Messages API(구조화 출력 포함)를 실제로 연동해보는 학습/실험 목적도 겸하고 있다.

## 타겟 사용자
- 개발자 본인(1인 사용, 현재 이직/구직 준비 중). 로그인/다중 사용자 개념 없음.
- 브라우저 하나에서, 로컬 환경에서 띄워놓고 쓰는 개인용 도구.

## 목표
1. 이력서 원문(텍스트/마크다운/PDF)을 등록하고 채용공고 JD를 붙여넣을 수 있다.
2. AI와 대화하면서 이력서를 JD에 맞게 다듬을 수 있고, AI가 제안하는 수정본을 한 번의
   클릭으로 적용할 수 있다.
3. 수정 이력을 버전으로 남겨 되돌릴 수 있다.
4. 최종본을 복사하거나 파일로 내려받을 수 있다.

## 성공 기준 (개인용 툴이므로 정성적 기준)
- 채용공고 하나당 "이력서 붙여넣기 → JD 붙여넣기 → 대화 몇 번 → 적용 → 다운로드"까지
  5분 내로 끝낼 수 있다.
- 이전에 적용했던 수정본으로 되돌리는 데 별도 설명 없이 버전 목록에서 바로 가능하다.
- 서버가 이력서/JD/대화 내용을 DB에 남기지 않는다는 점에서, 개인정보(이력서) 유출
  경로가 브라우저 localStorage + 선택한 AI 제공자(Anthropic 또는 Google Gemini) API 호출
  두 곳으로 한정된다.

## 비목표 (하지 않는 것)
- 여러 사용자를 위한 서비스화, 로그인/인가
- 이력서 품질을 자동으로 "점수화"하는 기능
- 채용공고 크롤링/자동 수집
